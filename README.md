# אקורדים

אפליקציית אנדרואיד שמזהה אקורדים, סולם, מהירות ומשקל של שיר — הכול בטלפון, בלי אינטרנט.

- נגן: האקורדים רצים על הביט, קלידים מנגנים את האקורד, לחיצה על אקורד מציעה 4 חלופות
- סולם: העלאה/הורדה בחצאי טונים, כולל שינוי גובה השיר עצמו, ומהירות נגינה לתרגול
- גיטרה: ציורי אקורדים, קאפו עם חישוב אוטומטי והמלצה על הקאפו הנוח
- פרטים: BPM, משקל, סולם, כיוון, רשימת אקורדים

ה-APK נבנה אוטומטית ב-GitHub Actions ומתפרסם ב-Releases.
